# Introduction

NLP notes, from classical text features through to transformers. The classical end is applied in [duplicate-question-detector](https://github.com/Ram-466/duplicate-question-detector) — TF-IDF cosine similarity, fuzzy string matching, and n-gram overlap on ~400k Quora question pairs.

## Why this matters
These notes exist to make the concepts reusable. Anything written here should be
something I can explain out loud in an interview without looking it up.

## Format
Each note follows the same shape:
- **What it is** — the plain-language definition
- **Why it matters in ML** — where it actually shows up in practice
- **Code** — a minimal worked example, cross-linked to `snippets/`
- **Gotchas** — what trips people up
